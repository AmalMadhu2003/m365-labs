# Microsoft 365 labs

Hands-on labs in a practice Microsoft 365 tenant, built around a fictional medical clinic. Each lab covers what I built, why I made each design decision, and what went wrong and how I fixed it.

| Lab | Topic | Skills |
| --- | --- | --- |
| [01](lab-01-identity-foundations) | Identity foundations | Users, licensing, bulk onboarding, security, Microsoft 365 and dynamic groups |
| 02 | Locking the front door *(coming next)* | MFA, Conditional Access, break-glass account, admin roles |

**Stack:** Microsoft 365 Business Premium · Microsoft Entra ID P1 · Intune · Defender for Business

All users are fictional; no real patient or employee data is used.
